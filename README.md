## Overview

This project involves designing a basic ESP32 Development Board using **KiCad**, an open-source electronic design automation (EDA) software.

The objective was to understand the fundamentals of PCB design, including schematic creation, component placement, PCB layout, routing and 3D visualization.

## Tools Used

- **PCB Design Software:** KiCad
- **Microcontroller Platform:** ESP32
- **Design Type:** Development Board PCB

## Project Structure

- `KiCad-Project/` – Contains the KiCad schematic, PCB layout and project files.
- `Images/` – Contains schematic, PCB layout and 3D visualization screenshots.
- `Fabrication-Files/` – Contains manufacturing files, if generated.
